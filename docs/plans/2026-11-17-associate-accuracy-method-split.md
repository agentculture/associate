## End state

### Announcement

- associate ships an accuracy method (issue #20): every tool call in a run carries a purpose the model stated before it ran and a harness-written record of what was asked, what was sent, how it ended and what came back; every fact the model reports cites the walk entry it came from and quotes that entry's saved result word for word, and a deterministic matcher in the harness checks each quote; conclusions carry the numbered facts they rest on and name their source kind (file read, tool call, agent conclusion, memory, web); and each run reports countable accuracy — how many facts and claims were made, checked, passed and refused, per kind — so an operator can follow any answer link by link back to saved results without re-running anything

### After state

- a finished run hands back, beside its answer, a walk in which every action has a stated purpose and a harness-written record, a list of facts each tied to one walk entry by a quote the harness matched, conclusions that name the facts they rest on, and a count of what was made, checked, passed, refused and left unchecked; a hand-back that fails the check is refused in session and, if still failing, ends the run with a named reason

### Success signals

- on a fixed set of at least 5 read or find tasks with hand-checked answers, run live on worker and on cortex, every fact reported as passed is found word for word in the saved result of the entry it cites when re-checked by the Python harness (0 mismatches), and the harness's counts equal a hand count of the same hand-backs
- replaying the 2026-11-17 failures as tests, 4 of 4 are caught: an invented [w999] id in a final message, a fact quoting text absent from the cited entry, an id of a prior run cited in a continued run, and a call made with no purpose
- two further recorded failures are replayed as tests and 2 of 2 are caught: the cortex sentence about pyproject.toml carried in a finish summary (scope20-cortex-t1), and the senses report of "Eidetic remember: Success" with no eidetic_remember call (t20 run A2)
