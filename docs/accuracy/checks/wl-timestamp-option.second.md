# wl-timestamp-option: second check

## What I was given

The question "append option setting timestamp" about workledger-cli at its pinned commit; I did not see the first check or any expected answer.

## Commands and what they showed

append.py register lines 346-358; _store.py validate_input lines 133-139.
(Read-only grep/cat/sed/python-json over the clone; no repository code was run.)

## Answer

None. append takes only `entry` (positional JSON), `--stdin` and `--json`. The timestamp is generated (now_utc, UTC ms precision). Supplying `timestamp` or `id` inside the JSON is rejected as a user error (exit 1) 'field(s) are generated by the ledger and cannot be supplied'.

## Confidence and doubts

high
